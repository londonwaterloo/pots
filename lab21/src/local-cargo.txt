Запуск программ локально с помощью Cargo

Если вы хотите экспериментировать с кодов на своем компьютере, сначала надо установить Rust. 
Сделайте это следуя инструкциям на странице https://www.rust-lang.org/tools/install. 
После этого в вашем распоряжении будут компилятор rustc и cargo.

% rustc --version
rustc 1.69.0 (84c898d65 2023-04-16)
% cargo --version
cargo 1.69.0 (6e9a83356 2023-04-12)

Вы можете использовать любую более позднюю версию.

With this in place, follow these steps to build a Rust binary from one of the examples in this training:

Click the “Copy to clipboard” button on the example you want to copy.

Для создания каталога  нового приложения наприер с именем exercise введите команду:

$ cargo new exercise
     Created binary (application) `exercise` package
Перейдите в каталог и запустите программу с помощью другой команды cargo:

$ cd exercise
$ cargo run
   Compiling exercise v0.1.0 (/home/mgeisler/tmp/exercise)
    Finished dev [unoptimized + debuginfo] target(s) in 0.75s
     Running `target/debug/exercise`
Hello, world!
Замените код примера в src/main.rs вашим кодом. Например:

fn main() {
    println!("Отредактируй меня!");
}

Снова запустите cargo для сборки и запуска обновленной программы:

$ cargo run
   Compiling exercise v0.1.0 (/home/mgeisler/tmp/exercise)
    Finished dev [unoptimized + debuginfo] target(s) in 0.24s
     Running `target/debug/exercise`
Отредактируй меня!!

Используйте команду cargo check для быстрой проверки проекта на ошибки, 
используйте команду cargo build для сборки программы без запуска. Бинарный файл находится в папке target/debug/ для отладочной версии. 
Используйте команду cargo build --release для сборки оптимизированной релизной версии в каталоге target/release/.

Вы можете добавить зависимости к вашему проекту в файле Cargo.toml. При сборке проекта неоостающие зависимости будут автоматически 
загружены и скомпилированы.
